# Diabetes Model Tuning

## Goal

Diagnose and control model complexity, then systematically tune
regularized linear models and Support Vector Regression using
validation-based model selection.

## Dataset

Scikit-learn Diabetes dataset

442 observations
10 numerical input features
continuous regression target

## Evaluation Protocol

Train:
model fitting

Cross Validation:
model selection and tuning

Test:
held untouched until final evaluation

## Lesson Scope

- Model Complexity
- Bias / Variance
- Learning Curves
- Ridge / Lasso / ElasticNet
- p-values
- GridSearchCV
- RandomizedSearchCV
- Coarse / Fine Search
- SVR / Kernels
